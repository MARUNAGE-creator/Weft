🎯 いつ使う?
自分のペンネームや「@hogehoge」のキャラで note を量産したい時。SHIN さんの「のうみそ恋愛研究所🧠」のような 持続的なブランド運用 を Weft で再現するため。
📍 場所(v0.11.1 で見つけやすく独立セクション化)
画面上部の「①API 設定」「②文体プロファイル」の すぐ下 に「🎭 ペルソナ情報(任意・ブランド一貫性を強化)」パネルがある。クリックして開く → 5項目を入力(全部任意)。
📝 入力項目(全部任意)
・ペルソナ名 / 名乗り(例:「のうみそ恋愛研究所🧠」)
・タグライン(例:「全部、脳のせいです。」)
・口癖・語感(カンマ区切り、例:「ガチで, マジで, めっちゃ」)
・よく使う絵文字(例:「🧠 ✨ 🤍」)
・著者紹介(200-400字、本文の自己紹介セクションで使う)
⚠️ 注意
ペルソナ情報を 有効にするには「②文体プロファイル」の ON チェックも必要。ペルソナ情報だけ入力 + 文体プロファイル OFF だと反映されません。

💎 裏技・節約テクニック

Gemini API の無料枠(1日 1,500回)を 実質的に拡張・温存 するためのテクニック集。テスター運用で本当に効くやつだけ。

🎭 ① Google アカウント複数戦略(無料枠 ×N 倍)

💡 概要
Gemini API キーは Google アカウントごとに発行される。1日 1,500回の枠は アカウントごとに独立。複数 Google アカウントを持っていれば、それぞれで API キーを取得して切り替えるだけで 無料枠が実質 3,000 / 4,500 / ... 回に増える。
⚙️ やり方
1. 別の Google アカウント(仕事用・個人用・サブ垢など)で aistudio.google.com/app/apikey にログイン
2. 「Create API key」で新規キー発行
3. Weft の「① API 設定」で API キー欄を差し替え → 保存
4. 1日の枠を使い切ったら次のキーに切り替え
📊 効果
アカウント数 ×1,500 回/日。3アカウントなら 1日 4,500回 = 200〜300 記事分の余裕。
⚠️ 注意
各アカウントの Google 利用規約は遵守すること。営利利用の規模が大きい場合は有料プランへ。

🚀 ② 構成だけ Weft、本文は外部 AI に渡す(王道の節約術)

💡 概要
Weft 内の本文生成は重い(1記事で +1回 + 長い時間)。構成までを Weft で作って、本文は Claude / ChatGPT / Gemini Pro の Web 版に渡す と、Weft の無料枠を温存できる + 外部 AI の独立した無料枠も使える。
⚙️ やり方
1. Weft で「リサーチ&分析」→ タイトル選択 → 構成案を確認(必要なら再構築)
2. ④ ドラフトの「📁 各 AI 用プロンプトをコピー」→ Claude / ChatGPT / Gemini Pro を選択
3. 各 AI の Web 画面で貼り付けて本文を書かせる
4. Weft 内の「本文を生成」ボタンは使わない
📊 効果
Weft の API 消費が 記事あたり -1回。Claude / ChatGPT 無料プランの枠も活用可能。長文(特大・超特大)は外部 AI の方が圧倒的に安定。
🏆 おすすめ AI 別の使い分け
Claude(文体保持・読み物系・長文の自然さ)/ ChatGPT(実用ノウハウ系・構造化)/ Gemini Pro Web(API とは別枠、大量素材OK)

📝 ③ 動画要約は「概要文(節約)」で代替する

💡 概要
YouTube 動画要約は1動画あたり Gemini AI 視聴で +1回 + 数十秒と重い。すべての動画を AI 視聴する必要はなく、多くの場合は概要文(タイトル + 説明欄)で十分な情報が取れる。
⚙️ やり方
1. YouTube 結果が並んだら、本当に深掘りしたい1〜2本だけ「✨ 動画で要約」
2. その他は「📝 概要文(節約)」 or 「💰 全て概要文で」を選択
3. 動画10本中、AI 視聴は2本に抑える運用が現実的
📊 効果
動画10本フル AI 視聴で +10回だったところを、+2回に削減。YouTube 機能を使う1リサーチあたり -8回の節約。

💾 ④ 過去プロジェクト保存でリサーチを流用

💡 概要
同じテーマで 記事の方向性違いを試したい 時、リサーチを再実行するのは無駄。「💾 プロジェクトに保存」しておけば、過去履歴から呼び出してタイトルや構成だけ変えて何度でも本文化できる。
⚙️ やり方
1. リサーチ完了 → 構成確定の時点で「💾 ここまでをプロジェクトに保存」
2. 別の角度で記事を作りたい時、「📂 過去のプロジェクト」から復元
3. タイトルだけ再生成 → 構成だけ再構築 → 別の角度の記事が完成
4. シリーズ展開モード で過去プロジェクトを読み込めば、派生記事5本が一気に出る(さらに効率)
📊 効果
1リサーチ(15-25回)で 2-3本の記事を派生可能。同じテーマで連載する人には必須テクニック。

🎯 ⑤ 特大・超特大は「Weft 構成のみ + 外部 AI 本文」専用と割り切る

💡 概要
10,000字超の長文は、Gemini API の出力で 途中切れリスク + 時間がかかる。Weft 内本文生成じゃ実用に耐えない。構成だけ Weft、本文は Claude / ChatGPT で書く 運用が現実的。
⚙️ やり方
1. 長さは「特大」or「超特大」を選択
2. 「本文を生成」ボタンは押さない
3. ④ ドラフトの「📁 各 AI 用プロンプトをコピー」→ Claude 推奨(長文耐性高い)
4. Claude.ai(無料プラン)に貼って本文書かせる
5. 必要なら ChatGPT で整形(note 直貼り用に Markdown 整理)
📊 効果
Weft の API 消費なし(構成生成 +1回のみ)。Claude / ChatGPT の独立した無料枠で長文を仕上げる。

🔄 ⑥ シリーズ展開モードを最初に1回叩く(連載前提なら最強)

💡 概要
1本目の記事を書く前に、まず 「📚 既存記事から」タブで仮の本文を入れてシリーズ展開モード を1回回す。連載5本のロードマップが先に出るので、各記事のリサーチが最小限で済む。
⚙️ やり方
1. 仮の記事概要(箇条書きでも OK)を「📚 既存記事から」タブに入れる
2. 動線タイプ「📋 ファネル設計」を選択
3. 「シリーズ展開を実行」 → 5本連載のロードマップ + 派生記事案 + Threads 候補が一気に出る
4. その後、各記事を Weft で1本ずつリサーチ&分析していく
📊 効果
「次に何を書けばいいか」で詰まる時間が消える + Threads 投稿候補も同時に取れる。シリーズ展開 +1回の消費で、5本分の方向性が固まる。

🚨 困った時のチェック

  • 「Gemini レート上限」エラー → 自動カウントダウン後に再試行(約51秒待つ)
  • 「429 / quota exceeded」 → 1日無料枠(1,500回)を使い切った可能性。日本時間 午後4〜5時頃にリセット(米国西海岸の午前0時)
  • 本文が途中で切れる → 記事の長さを「短め」に下げる、または再生成
  • 構成案が空 → 「リサーチ&分析」を再実行
  • YouTube に変な動画(中国ドラマ等) → カテゴリから選ぶと AI 拡張で日本語キーワードに絞れる
  • 論文 0件 → 上部の AI 拡張キーワードを確認、テーマを少し抽象化して再試行
  • F12 のコンソールで詳細なエラー内容が見れる(原因切り分けに有効)
