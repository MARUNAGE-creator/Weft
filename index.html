クロスリサーチ note 記事生成エンジン

Weft

横糸を、あなたの言葉に。

Weft は、note.com / YouTube / 知恵袋 / 学術論文 / Google Trends を横断して実データで調査し、競合記事と差別化された note 記事の構成・タイトル・本文をワンストップで生成するブラウザツールです。

AI 知識ベースの推測ではなく、実データに基づく分析 と あなた自身の視点 を組み合わせて、有料 note の品質に近づけます。

Launch アプリを起動する → Manual / PDF 取扱説明書を読む ↗

主な機能

  • 5つのデータソースを横断したクロスリサーチ(note / YouTube / 知恵袋 / 論文 / Trends)
  • 競合パターン・空きスポット分析と、◎○△ 評価付きのタイトル提案
  • 知恵袋・論文の知見を踏まえた構成案の自動統合(v0.9.2)
  • 過去 note 記事を学習する文体プロファイル(最大3本)
  • Weft 内 Gemini 生成、または Claude / ChatGPT / Gemini Pro へのプロンプト出力
  • API キーはあなたのブラウザにのみ保存され、外部に送信されません
初めて利用する方へ: アプリを起動すると、まず Gemini API キー(無料、aistudio.google.com で取得)の入力を求められます。詳しくは取扱説明書 PDF をご覧ください。
