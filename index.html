クロスリサーチ note 記事生成エンジン

Weft

横糸を、あなたの言葉に。

Weft は、note.com / YouTube / 知恵袋 / 学術論文 / Google Trends を横断して実データで調査し、競合と差別化された note 記事の構成・タイトル・本文・さらに シリーズ展開戦略 までワンストップで設計するブラウザツールです。

AI 知識ベースの推測ではなく、実データに基づく分析 と あなた自身の視点 を組み合わせて、有料 / 無料 note の品質を一段引き上げます。

Launch アプリを起動する → In-App Manual アプリ内マニュアルを見る(機能ガイド + 裏技) ↗
⭐ What's new — v0.10.x
  • シリーズ展開モード:既存記事から派生記事5本 + Threads 投稿候補 + 改善診断を一気に生成
  • 有料 / 無料 note の切り替え:無料 = 情報商材型(視点で完結)/ 有料 = 学習商材型(行動が変わる)
  • 記事の長さ 5段階:短め 2,500字 → 超特大 13,000字まで対応
  • アプリ内マニュアルタブ:機能カード + トークン消費表 + 裏技6本(Google アカウント複数戦略など)
  • UI 整理:アコーディオン折りたたみ + フローティング目次で縦長スクロール解消

主な機能

  • クロスリサーチ:note.com / YouTube / 知恵袋 / 学術論文(OpenAlex 2.5億論文)/ Google Trends を横断して実データ分析
  • 競合パターン × 空きスポット分析 + 評価マーク(◎○△)付きタイトル提案3案 + 全素材を踏まえた構成案
  • シリーズ展開モード:既存記事 → 派生記事5本(深掘り / 対比 / 実践 / 体験談 / 応用)+ ファネル設計 + Threads 投稿候補 + 改善診断
  • 有料 / 無料 note の構造分岐:課金タイプで構成・文体・タイトル方針が自動切替
  • 文体プロファイル:過去 note 記事を最大3本まで学習、新記事に文体を継承
  • 本文生成 = 2系統:Weft 内 Gemini 生成 or Claude / ChatGPT / Gemini Pro 用にエクスポート
  • API キーはブラウザ内のみ保存、外部サーバーに送信されません
初めて利用する方へ: アプリを起動すると、まず Gemini API キー(無料、aistudio.google.com で取得)の入力を求められます。
使い方は 画面上部の「📖 マニュアル」タブ でいつでも確認できます(機能カード + トークン消費の目安 + おすすめフロー + 裏技集)。
